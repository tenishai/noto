# The design record

Plans and specs under this directory are history, kept on purpose: each describes
noto (then named argus) as it was when that arc was planned. Later arcs changed earlier ones and nothing
here is updated after the fact. The current truth is the code, [ARCHITECTURE.md](../../ARCHITECTURE.md)
and its cards under [docs/arch/](../arch/), [design.md](../design.md) and
[operating.md](../operating.md).
